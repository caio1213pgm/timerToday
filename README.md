# TimerToday

TimerToday é basicamente um gerenciador de tasks simples e eficiente.

Futuramente, o projeto contará com:
- **Histórico de tasks**
- **Espaço para anotações**
- **Conexão com o Firebase** para salvar todas as suas tasks e anotações na nuvem, sem perder nada.

## 🚀 Principais Tecnologias (Stack)

- **React** (v19)
- **TypeScript**
- **Vite**
- **Day.js** (Manipulação de datas/tempo)
- **Lucide React** (Ícones)
- **CSS Modules** (Estilização)

## 📌 Pré-requisitos

- **Node.js**: `v22.17.0` (versão utilizada/recomendada)
- **Gerenciador de pacotes**: npm, yarn ou pnpm

## 🛠️ Como executar o projeto

1. Clone o repositório (caso ainda não tenha feito):
   ```bash
   git clone <url-do-repositorio>
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no seu navegador a URL informada no terminal (geralmente `http://localhost:5173`).
